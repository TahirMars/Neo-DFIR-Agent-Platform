## 使用时机

在 `generate_report` / 报告智能体整合子 Agent 输出时使用本技能。

## 检查项

1. **执行摘要**：是否包含事件类型、影响范围、威胁等级、关键时间，且与后文一致。
2. **攻击链**：是否提供可解析的 Mermaid 图；节点 ID 是否仅用英文/数字/下划线。
3. **举证**：每条关键结论是否标注证据来源（日志路径、样本哈希、情报查询结果）。
4. **IOC 表**：文件 IOC 与网络 IOC 是否分表；未知项是否标为 unknown 而非臆造。
5. **处置建议**：是否区分紧急/短期/长期，并给出可执行动作。
6. **局限性**：是否说明数据缺口或未能覆盖的分析类型。

## 与工具的配合

- 需要证据清单时调用 `get_evidence_summary`。
- 需将关键结论写入跨会话记忆时调用 `case_memory_update`（章节如：`案件概要`、`已确认 IOC`）。
